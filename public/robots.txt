# BT Servant — crawl policy
#
# Everything on this site is public and the point of the site is to be found:
# people should be able to discover BT Servant through search engines and AI
# answer engines alike. Every crawler is allowed: search engines, live-retrieval
# agents (the fetchers behind ChatGPT search, Perplexity, Claude search,
# Copilot, Gemini grounding) AND bulk training crawlers. Each is named in its
# own group so a broader per-agent rule elsewhere cannot override it.
#
# TRAINING POLICY: allow all, including training, the same decision as
# openbiblestories.org (unfoldingWord/obs-website#15) and translationcore.com.
# Cloudflare's managed robots.txt for this zone must therefore be OFF, or it
# prepends `Content-Signal: ai-train=no` and `Disallow: /` for GPTBot,
# ClaudeBot, Google-Extended, CCBot and the rest. That setting lives in the
# Cloudflare dashboard, not in this file (see docs/deployment.md).
